# E-Wallet · Supabase Sync

File principali per GitHub Pages:
- `index.html` — applicazione principale con accesso e sincronizzazione Supabase
- `sw.js` — cache PWA/offline
- `ewallet.html` — copia standalone dell’app

## Prima migrazione
Aprire per primo il nuovo sito sul Mac che contiene già tutti i dati locali, accedere con l’utente Supabase e attendere il badge “Sincronizzato”. Solo dopo aprire l’app sugli altri dispositivi.

Il token GitHub/Gist non è più necessario per la sincronizzazione.
